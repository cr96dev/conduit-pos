# Conduit POS — Prompts de Image Generation

Prompts paste-ready para Gemini (Imagen 3 / 4) o Midjourney. Cada uno produce un panel del brand-guidelines board.

**Tips antes de empezar:**
- En Gemini elegí "Imagen 4" o el modelo más reciente para mejor tipografía
- Generá 4 variantes por prompt, elegí la mejor, opcionalmente "remix" para iterar
- Para tipografía precisa, Gemini todavía falla a veces — si una palabra sale mal escrita, regenerar o usar herramienta externa (Photoshop, Figma) para overlay limpio
- Aspect ratio sugerido al final de cada prompt
- Si Gemini rechaza por nombre comercial (raro), reemplazá "Conduit POS" por "Conduit" solo

## Cómo usar los prompts

1. Abrir Gemini (o tu image-gen preferido)
2. Pegar el prompt del Panel 1
3. Generar 4 variantes
4. Elegir la mejor, descargarla con nombre `panel-01-hero.png`
5. Repetir con Panel 2, 3, 4...
6. Una vez tengas los 9, mandame el folder y armo el board final en HTML/PDF para pitch deck

## Lo que NO va a salir perfecto en image-gen

Image-gen models suelen fallar en:

- **Texto preciso pequeño** — si "Conduit" sale como "Conudit" o "Conduiit", regenerar. Si persiste, hacer overlay manual en Figma/Photoshop.
- **Logos con geometría exacta** — el C con barra horizontal puede salir mal proporcionado. Mejor confiar en el SVG vectorial (`logos/concept-a-canal.svg`) y compositarlo manualmente sobre fotos.
- **Receipts impresas legibles** — el contenido textual del ticket puede salir random. Para producción real conviene hacer mockup en Figma usando el SVG real + texto real.

**Workflow recomendado:** usar Gemini para las **fotos atmosféricas** (Panel 4, 5, 6, 7), y armar los **paneles de tipografía/logo** (Panel 1, 2, 3, 8, 9) en Figma con los SVGs y tokens reales del repo.

Eso te da el máximo de calidad sin pelearte con la limitación de tipografía de los image-gen.
